🚀 AWS Static Website CI/CD Project

Version 3.0

This website is automatically deployed using a complete CI/CD pipeline built with GitHub, Jenkins, AWS IAM, and Amazon S3.

Every code change pushed to GitHub automatically triggers a Jenkins Pipeline, which validates the source code and deploys the latest website version to Amazon S3 with minimal manual intervention.

Key Features

  • ✅ Continuous Integration (CI)
  • ✅ Continuous Deployment (CD)
  • ✅ Automated Build & Release Process
  • ✅ Amazon S3 Static Website Hosting
  • ✅ AWS IAM Authentication
  • ✅ Jenkins Pipeline Automation
  • ✅ Version Controlled Infrastructure
  • ✅ End-to-End DevOps Workflow
