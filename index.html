🚀 AWS Static Website CI/CD Project

Version 3.0

This website is automatically deployed using a complete CI/CD pipeline built with GitHub, Jenkins, AWS IAM, and Amazon S3.

📋 Project Overview

Source Code Repository: GitHub

Build Automation: Jenkins Pipeline

AWS Authentication: IAM User & Access Keys

Deployment Target: Amazon S3

Hosting Type: Static Website Hosting

Deployment Method: AWS CLI & Jenkins AWS Steps Plugin

🏗 CI/CD Workflow

Git Push
↓
GitHub Repository
↓
Jenkins Pipeline
↓
AWS Credentials
↓
Amazon S3
↓
Static Website Hosting

Linux (RHEL/Rocky Linux) | Git & GitHub | Jenkins | AWS IAM | AWS CLI | Amazon S3 | Pipeline as Code (Jenkinsfile) | CI/CD Automation
